# Notas de Git

- **Working area:** ficheiros alterados, ainda sem git add.
- **Staging area:** alterações preparadas com git add.
- **Repositório local:** commits feitos com git commit.
- **Repositório remoto:** o GitHub, atualizado com git push.
- **Stash:** guarda alteracoes temporariamente com git stash e recupera-as com git stash pop.
